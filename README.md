# frontend-cc-platform

SPA (React + TypeScript + Vite) para la plataforma de Cuentas Corrientes y Cobranzas de Pontyn.

## Cómo correrlo

```bash
npm install
npm run dev
```

## Configuración local

La app ya tiene valores por defecto (URL de la API, tenant/client ID de Entra) que funcionan out of the box.
Si necesitás apuntar a otro entorno, copiá `.env.example` a `.env.local` y ajustá los valores ahí — `.env.local` los sobrescribe sin necesidad de tocar el código.
